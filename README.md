# TAC FC downloads

Direct downloads for TAC FC (https://tacfc.com), the free online football manager.

Get the latest version from https://tacfc.com/download.

- Windows: TAC FC setup (.exe). Windows SmartScreen may warn because the installer is not code signed: choose More info, then Run anyway.
- Mac: TAC FC (.dmg), signed and notarized by Apple.
- Android: TAC FC (.apk). Allow installs from this source when asked.

The desktop app in `desktop/` is a small Tauri window around https://tacfc.com.
